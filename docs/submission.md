# Submitting

**One submission per team. Due 4:00 PM.** You can submit early and keep building. Edit your
submission any time with the edit code from your receipt. Save that code. If you lose it, find an organizer.

## The form

On the event hub: **<https://faithtech-socal-hackathon.vercel.app/#submit>**

| Field | Notes |
|---|---|
| Team name | |
| Track | 1, 2 or 3 |
| Who it is for | One line |
| What it does | A few sentences: what a person can do with it today |
| GitHub repo | If you have one. Public. |
| Link to see it | A live app, a prototype (Figma, Lovable, Replit), slides or a doc |
| Demo video | Optional. A 60 to 90 second walkthrough ([how](demo-video.md)) |
| Team members | One name per line |
| Contact name and email | For organizers to reach your team |

**You need a GitHub repo or a link to see it. One is enough.** A team that built without code,
or didn't get to GitHub, can still submit a link a judge can open on a phone.

## If you have a repo

- [ ] The repo is **public**.
- [ ] A README that follows [`templates/TEAM-README.md`](../templates/TEAM-README.md).
- [ ] A license file. MIT is fine.
- [ ] The README says **how to run it**, so someone who is not on your team can.
- [ ] **Test data only.** No real church, pastor or person data. See
      [ground rules](ground-rules.md).
- [ ] No API keys or passwords in the repo or its history.

## If you have a link

- [ ] It opens without a login (or put a test login in "What it does").
- [ ] It works on a phone.
- [ ] Shared as "anyone with the link can view" (Google Drive, Figma, Loom).

## New to GitHub?

You don't need it to submit. If you want it, one teammate with a free account is enough: on
github.com choose **New repository**, make it public, then **Add file**, **Upload files**.
Stuck? Find a mentor well before 4:00.

## After 4:00

Demos start at 4:30: 3 minutes each, then 2 minutes of questions. See [judging](judging.md).
If you have a repo, it stays public so the work can be picked up later. That is stewardship, not a
claim on your IP.
