# Judging

**Judging as of Oct 23.** These are the proposed criteria and may change. The final version is
shared on the day.

## Demo format

- **90 seconds** of a working prototype, then **what God did** in your team.
- It is a **demo, not a pitch.** We already know the problem.
- Judges get a quick Claude read of each repo before demos, so a clear README helps.

## Honors

Announced in this order:

| Honor | Picked by |
|---|---|
| **Most Collaborative** | The mentors |
| **Most Creative** | The judges |
| **Most Redemptive** | Highest weighted judge score (below) |

An optional **Baptize's Pick** may be chosen by Pastor Calin.

## Most Redemptive: proposed scoring

| Weight | Question |
|---|---|
| **35%** | Does it work live, end to end? |
| **30%** | Would Baptize The World adopt it? |
| **20%** | Can a non-technical pastor or new believer use it? |
| **15%** | Is it built the way we said: consent, honest data, team care? |

## What helps

- A prototype that runs, even if small.
- A README a stranger can follow ([template](../templates/TEAM-README.md)).
