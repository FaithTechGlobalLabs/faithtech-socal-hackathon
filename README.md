# FaithTech SoCal × Baptize The World Hackathon

**Saturday, October 24, 2026 · 9:00 AM to 6:00 PM · The Robertson Triangle, 3390 Robertson Pl, Los Angeles**

One day to build for the global church. Pick one of three challenges from Baptize The World, form
a team and ship something real. Code freeze is at 4:00 PM, and demos start at 4:15.

Baptize The World is a global movement uniting churches in baptism. On Pentecost 2026, more than
1,600 churches in 49 countries reported 17,910 baptisms. The next global day of baptism is
Pentecost, May 16, 2027. Hosted by FaithTech LA and FaithTech OC.

## Build rules

1. **Start fresh.** The code starts today.
2. **Any stack.** Open source, APIs and AI tools welcome.
3. **Test data only.** No real personal data from churches.
4. **Credit your sources.** Name the tools and templates you used.
5. **Code freeze at 4:00.** Working beats perfect.
6. **Public repo.** Keeps the code open for others to steward.

Use a public repo on your own GitHub account. If your team wants its repo in FaithTech's GitHub
org, ask Travis or Jesse to add you, and have your GitHub username ready. Full boundaries:
[ground rules](docs/ground-rules.md).

## Teams

Teams of 3 to 5. Mix builders, designers and church voices. Every team needs a **Project Lead**
and a **Dev**. Vibe-coding is okay. Name your direction before lunch:

> We help [audience] to [do the central atomic action] by [the technology you've created].

## How we build

Every team moves through the Create Cycle, and works through each step in Pathfinder:
**Lament** (10:30), **Discern** (11:00), **Build** (12:30 to 4:00: pray, prototype, pause) and
**Steward** (3:00 to 4:00: Tend, Examine, Testify). Read [the Create Cycle](docs/create-framework.md).

## Judging

Judges score each team 1 to 5 on three questions. Redemptive potential carries 40% of the score,
and the other two carry 30% each.

| Criterion | The question |
|---|---|
| **Redemptive potential (40%)** | Could this advance the gospel and reach real people, beyond the demo? |
| **Usable by the end user (30%)** | Could a pastor, a new believer or a church volunteer use it without us in the room? |
| **Technical viability (30%)** | Does it work live, end to end, and could it fit into Baptize The World's tech stack? |

Honors: **Most Redemptive** (top score), **Most Collaborative** (mentors' pick) and **Most
Creative** (judges' pick). Details: [judging](docs/judging.md).

## Why the code lives on GitHub

Not for ownership. FaithTech and Baptize The World are not claiming your IP. A public repo means
that if your team steps back after today, the work stays available for someone to pick up and
steward. Add an open-source license (MIT is fine) and a short README using
[the team template](templates/TEAM-README.md).
