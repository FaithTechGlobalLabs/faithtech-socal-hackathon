# FaithTech SoCal × Baptize The World Hackathon

**Saturday, October 24, 2026 · 9:00 AM to 6:00 PM · The Robertson Triangle (Intersections LA), 3390 Robertson Pl, Los Angeles**

One day, three real problems from Baptize The World, a global movement that invites churches to
baptize on Pentecost Sunday and counts every baptism. Small teams build a working prototype.
Hosted by FaithTech LA and FaithTech OC.

Baptize The World runs on five volunteers, spreadsheets and phone calls. Churches want to take
part, and the friction stops them. Today we build the tools that remove it.

**Event hub (schedule, submit form):** <https://faithtech-socal-hackathon.vercel.app>

**First hackathon?** You do not need a team, an idea or coding experience. Read
[your first hackathon](docs/first-hackathon.md). Two minutes.

## Pick one track

| | Track | How might we... | Folder |
|---|---|---|---|
| 1 | **Mobile-first church onboarding** (top priority) | make registering a church and reporting baptisms as easy as sending a text? | [tracks/1-mobile-church-onboarding](tracks/1-mobile-church-onboarding/) |
| 2 | **Testimony sharing** | make it easy for someone who was just baptized to share their story? | [tracks/2-testimony-sharing](tracks/2-testimony-sharing/) |
| 3 | **The first 30 days** (stretch) | walk with someone through their first 30 days after baptism? | [tracks/3-first-30-days](tracks/3-first-30-days/) |

Each folder has the problem, who it is for, what "done at 6 PM" looks like, the boundaries, and
made-up test data you can build against.

## Build rules

1. **Start fresh today.** Nothing built before the build starts counts.
2. **Any stack.** Use whatever you and your team know.
3. **Test data only.** No real church, pastor or person data. The files in each track are made up.
4. **Credit your sources.** Libraries, templates, prompts, other people's code.
5. **Code freeze at 4:00 PM.** Submit a public GitHub repo, a link a judge can open, or both. One is enough.

Full boundaries: [ground rules](docs/ground-rules.md).

## The Create framework

The day follows FaithTech Create: **Lament, Discern, Build, Steward.** While you build, you loop
through pray, prototype, pause. Read [the Create framework](docs/create-framework.md).

## Pathfinder

Pathfinder is FaithTech's lightweight team tool. Scan the QR to sign up, enter your laments and
carry them through the day. The link is posted at 9:00 AM. Code submissions still go through the
hub's Submit form unless announced otherwise. See [Pathfinder](docs/pathfinder.md).

## Why the code lives on GitHub

Not for ownership. FaithTech and Baptize The World are not claiming your IP. A public repo means
that if your team steps back after today, the work stays available for someone to pick up and
steward. Add an open-source license (MIT is fine) and a short README using
[the team template](templates/TEAM-README.md).
